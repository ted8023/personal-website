# 阿秋的个人名片网站 — 设计文档

> 日期：2026-06-06
> 状态：设计已确认，待编写实现计划
> 作者：阿秋（与 Claude 协作 brainstorm）

---

## 一、概述与目标

为「阿秋」打造一个**个人名片式网站**，用于创业、求职、建立行业影响力等场合——直接拿给别人看，让对方迅速知道：**我会什么、正在做什么、是个什么样的人。**

**核心印象（一句话）**：阿秋 = 又会做、又会写、还很有趣的**复合型选手**。

**两条硬性要求**：

1. **足够个性，第一印象先声夺人**——首页打开的瞬间就要立住人设、抓住人。
2. **作为产品经理的网站，导航 / 排版 / 交互必须合理、顺畅**——信息层级清晰，路径短，体验流畅。

---

## 二、目标受众与策略

| 场景 | 受众 | 关注点 |
| --- | --- | --- |
| 创业 / 找合伙人 | 潜在合伙人、投资人 | 在做什么、做成过什么、能否落地 |
| 求职 | 业务负责人、HR | 专业能力、方法论、代表作 |
| 行业影响力 | 同行、读者 | 思考深度、观点、内容 |

**策略：三者兼顾，不为单一场景牺牲。** 首页用**一个强人设**把所有人先抓住、让人会心一笑，再通过鲜艳色块分流到各自感兴趣的内容。

**基本设定**：

- 称呼：**阿秋**
- 语言：**中文为主**，专有名词保留英文（如 Vibe Coding、AI、PM）

---

## 三、设计原则与视觉气质

**视觉方向**：留白干净的底 × 鲜艳明亮的大色块。

- **背景**：以留白/浅色为主，干净、有呼吸感（参考极简风，但**不要"性冷淡"式的过度极简**）。
- **功能区 / 导航**：用**鲜艳、明亮、敢撞色的大色块**承载，制造活力与记忆点。
- **动效优先于装饰**：靠克制而当代的动效（如首页巨字循环、色块 hover 反馈）取胜，而非堆砌装饰元素。
- **趣味基调**：全站到处埋"小惊喜"（详见第七部分），这是个性的重要来源。

**五大板块主题色**（暂定，实现时可调得更大胆）：

| 板块 | 英文标签 | 主题色 |
| --- | --- | --- |
| 产品 | BUILD | 蓝 `#2563eb` |
| 写作 | WRITE | 橙 `#f59e0b` |
| 行业碎想 | THINK | 绿 `#10b981` |
| 哲思随笔 | MUSE | 紫 `#7c3aed` |
| 玩 / 兴趣 | PLAY | 粉 `#ec4899` |

> **像素级视觉不在本设计阶段定死。** 本文档锁定"气质 + 结构 + 交互原则"，最终配色、字体、间距、动效细节由实现阶段落地——附录 A 提供一份可直接喂给实现的「设计方向 Prompt」。

---

## 四、信息架构与导航

**结构：混合式枢纽（Hub + 预览 + 子页）。**

- **首页**：Hero 人设 + 5 个色块，**每个色块下带 2–3 条最新预览**（一眼看到在做什么/写什么），但**首页不暴露细节**（只显示分类名 + 英文标签，不露"狼人杀/电影"这类条目）。
- **子页**：每个色块的「查看全部 ▸」进入对应分类的完整页面。
- **导航**：顶部常驻导航栏（产品 · 写作 · 碎想 · 玩 · 关于），层级浅、路径短。

```
首页 (Hero + 5 色块预览)
├── /products   产品（BUILD）
├── /writing    PM 长文（WRITE）
├── /thoughts   行业碎想（THINK，绿）
├── /musings    哲思随笔（MUSE，紫）
├── /play       玩 / 兴趣（PLAY）
└── /about      关于
```

> 注：`/thoughts` 与 `/musings` **共用同一套"碎想流"布局组件**，仅主题色与标签不同。

## 五、页面规格

### 5.1 首页

- **上半屏（Hero）**：一行巨字人设，循环切换 **"我做产品 → 我写文章 → 我瞎想 → 也很会玩"**，末词高亮（渐变色）。配一行小字引导（如"嗨，我是阿秋 —"）。
- **下半屏（导航分流）**：5 个鲜艳色块，**bento 布局**（产品块更大、为主打）。
  - 每块显示：分类中文名 + 英文标签 + **2–3 条最新预览**（标题/缩略信息）+「查看全部 ▸」。
  - **不显示**细节条目（如具体电影名、狼人杀身份）。

### 5.2 产品页 `/products`（BUILD，蓝）

- 顶部：标题 + **类型筛选**（全部 / 网站 / 小程序 / App）。
- **主打作品**大卡：截图或动图、产品名、一句话简介、技术标签、**状态标签**（● 上线中 / 开发中 / 已下线）、**访问 ↗** 按钮 + 详情入口。
- 下方：作品**网格**（缩略图、名称、类型、状态、外链）。

### 5.3 写作页 `/writing`（WRITE，橙）

- 顶部：标题 + **话题筛选**（如 需求分析 / 增长 / AI 产品）。
- **置顶代表作**大卡：标题、摘要、发布时间、阅读时长、话题标签。
- 下方：文章**列表**（标题、阅读时长、话题）。
- 文章详情页：舒适的长文阅读排版。

### 5.4 碎想流 `/thoughts`（绿） & `/musings`（紫）

- **共用一套时间流布局**：时间倒序、标签筛选。
- 每条：日期 + 标签 + 1–3 句正文；较长的可点开看全文。
- `/thoughts` 标签示例：#AI #互联网 #产品观察；`/musings`：#哲学 #心理 #社会。

### 5.5 玩 / 兴趣页 `/play`（PLAY，粉）

- 三个**可展开模块**：
  - 🎬 **电影**：海报墙 + 评分 + 短评（"最近在看"）。
  - 🐺 **狼人杀**：爱用身份、风格、战绩 / 名场面。
  - 🎭 **剧本杀**：玩过的本、私藏推荐、想开的本。
- 模块结构可扩展，便于以后加新爱好。

### 5.6 关于页 `/about`

- 头像 + **第一人称自述**（有温度、有观点，不是简历）。
- **性格标签**（如 爱折腾 / 细节控 / 爱观察 / 话痨）。
- **联系方式**（邮箱、微信、GitHub、小红书等）。
- **🦉 可翻牌身份卡**彩蛋（呼应狼人杀，见第七部分）。

## 六、内容模型（Content Collections）

使用 Astro content collections，按类型组织 Markdown：

- **products**：`title, summary, type(网站|小程序|App), tech[], status(上线中|开发中|已下线), url, cover, featured(bool), order`
- **writing**：`title, summary, topic, publishDate, readingTime(自动估算可选), tags[], featured(bool)` + 正文
- **thoughts**：`date, tags[], body`（短内容直接 frontmatter 或正文）
- **musings**：同 thoughts 结构（独立集合，便于分主题色与筛选）
- **play**：电影 / 狼人杀 / 剧本杀分别用结构化数据（可用 Markdown 或本地数据文件），字段按模块定（如电影：`title, poster, rating, note, watchedDate`）
- **siteConfig / about**：站点基本信息、自述、性格标签、联系方式、身份卡内容

> 具体 schema 字段在实现计划阶段细化。

## 七、"有趣"层（埋点小惊喜）

全站个性的核心来源，确认为整站基调：

1. **首页巨字**：循环切换多重身份 + 可能的 hover 玩法。
2. **色块 hover**：活泼的微动效反馈。
3. **🦉 身份卡翻牌**（关于页）：呼应狼人杀，点击翻转看"阿秋的身份卡"。
4. **命令行彩蛋**：键盘敲特定指令（如 `whoami`）唤出隐藏的**"终端模式"**——把早期被否掉的极客风方案作为彩蛋复活。
5. **趣味 404 页**。
6. 其他光标 / 细节级小惊喜（实现时逐步加，不必一次到位）。

---

## 八、技术方案

- **框架**：**Astro**（专为内容驱动的静态站设计，content collections 管理作品/文章/碎想，构建快、SEO 友好）。
- **趣味交互**：在需要交互的局部使用 **Astro islands**（按需引入轻量组件，如身份卡翻牌、命令行彩蛋、首页动效）。
- **样式**：实现阶段确定（Tailwind 或原生 CSS，倾向 Tailwind 以便快速实现大色块/响应式）。
- **内容管理**：写 `.md`（或 `.mdx`）文件 → **Git 推送 → 自动部署**。
- **部署**：**Vercel**（先用免费子域名，自定义域名以后再接）。
- **响应式**：桌面与移动端都要顺畅（社交场合多用手机展示）。

## 九、v1 范围（Scope）

**包含**：

- 首页（Hero 动效 + 5 色块预览 + 导航）。
- 全部 6 个页面：产品 / 写作 / 碎想 / 哲思 / 玩 / 关于（含文章详情页）。
- 内容模型与 content collections（products / writing / thoughts / musings / play / about）。
- **示例占位内容**：每个集合放数条示例 `.md`/数据，搭好框架，阿秋之后替换为真实内容。
- 趣味层先实现：首页巨字动效、色块 hover、🦉 身份卡翻牌、趣味 404。
- 响应式 + 部署到 Vercel。

**暂不做（YAGNI / 以后再说）**：

- 命令行"终端模式"彩蛋——作为 v1.5 增量（架构预留，不阻塞首发）。
- Notion/CMS 后台、评论系统、访问统计/分析、多语言、深色模式、RSS。
- 自定义域名（先用 Vercel 子域名）。
- 真实内容填充（首发占位，后续由阿秋自行补充）。

## 十、成功标准

- 打开首页 **3 秒内**能感受到"这人有点东西、还挺有趣"——第一印象先声夺人。
- 任意访客能在 **2 次点击内**到达任一类内容。
- 五类内容都有清晰入口与得体的呈现；导航/排版/交互流畅无卡点。
- 阿秋能**只靠新增/编辑 Markdown 文件**完成日常内容更新。
- 桌面与移动端体验都顺畅。
